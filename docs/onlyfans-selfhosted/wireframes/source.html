How it works

Everything inside the dashed box is ours and self-hosted. No third-party OnlyFans SaaS.
Once, per creator — connect
Creatorclicks “Connect OnlyFans”
→
Hosted browserPlaywright Chromium on a sticky residential IP, streamed into the modal
→
onlyfans.comreal login, real captcha, real 2FA — done by the human
→
Session vaultcookies + x-bc + UA, encrypted, bound to persona
Continuously — read, reply, sell
Watcherone task per account: OF websocket, poll fallback
→
Event normaliserturns OF activity into our own signed webhook POST
→
/webhooks/onlyfansthe endpoint app.py already has — unchanged
→
Reply enginepersona prompt, funnel stage, PPV decision (unchanged)
→
of_clientsigns and sends: message, PPV, typing, tips
Signing
sign = SHA-1 of static_param:time:path:user-id, checksummed with the day's public rules. Rules refetched automatically the moment a request comes back “please refresh the page”.
Cost
Rules: free. Worker: one small always-on Cloud Run instance. Proxy: ~1 GB/account/month. No per-account SaaS fee — the whole cost sits inside the subscription price.
