Only personas with a connected Threads account can post or reply. Threads is public-only — no DMs.
How to connect
  1. Create a Meta app at developers.facebook.com and add the Threads API use case.
  2. In the app's Threads settings, add these scopes: threads_basic, threads_content_publish, threads_read_replies, threads_manage_replies.
  3. Set the Redirect Callback URI below as an allowed redirect URI in the app.
  4. Copy the app's Threads App ID and Threads App Secret into the fields below.
  5. Click Authorize on Threads, approve in the popup — done.
